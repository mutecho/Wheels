# Exp_femto_3d 数学物理公式流程说明

## 说明范围

本文按当前代码主线说明 `exp_femto_3d` 的数学/物理计算流程，以及每一步在程序里的抽象操作和代码位置。它描述的是当前工程化实现，不是完整的重离子 femtoscopy 教科书推导：

- 项目输入是实验 ROOT 文件中的 same-event 和 mixed-event `THnSparseF` 统计。
- 主工作流分为 `build-cf` 和 `fit` 两阶段。
- `build-cf` 从 7 维 sparse histogram 投影出三维 \((q_{\rm out},q_{\rm side},q_{\rm long})\) 相关函数。
- `fit` 对 `build-cf` 输出的 `CF3D` 做 3D Levy/Bowler-Sinyukov 拟合，并输出 \(R^2(\phi)\)、\(\epsilon_f(m_T)\) 等 summary。
- 当前 finite-source Coulomb 只实现 1D 球形 Gaussian 源的 CATS 表；各向异性 3D Coulomb kernel 不在当前实现范围内。
- `legacy/3d_cf_from_exp.cpp` 是参考宏，不进入当前 CMake 主构建。

## 符号约定

- 相对动量向量写作
  \[
  \mathbf q=(q_{\rm out},q_{\rm side},q_{\rm long})^T .
  \]
- \(q_{\rm out},q_{\rm side},q_{\rm long}\) 单位为 `GeV/c`。
- 半径参数 \(R^2\) 单位为 `fm^2`，有效半径 \(R_{\rm eff}\) 单位为 `fm`。
- 代码使用
  \[
  \hbar c=0.1973269804\ {\rm GeV\,fm}.
  \]
- \(\phi\) 表示 `#phi_{pair} - #Psi_{2}`，当前输入 sparse 的第 6 轴被视为该相对角。
- 当前代码把输入 sparse 轴按固定索引解释为：

  | 轴索引 | 物理/分析量 | 当前用途 |
  | --- | --- | --- |
  | 0 | \(q_{\rm out}\) | `TH3D` X 轴 |
  | 1 | \(q_{\rm side}\) | `TH3D` Y 轴 |
  | 2 | \(q_{\rm long}\) | `TH3D` Z 轴 |
  | 3 | \(m_T\) | build 分组选择 |
  | 4 | centrality | build 分组选择 |
  | 5 | (q_n) event-shape selector | qn-integrated 或逐 qn 切片 |
  | 6 | \(\phi_{\rm pair}-\Psi_2\) | phi-integrated 或逐 phi 切片 |

## 总体抽象流程

当前 CLI 流程可以抽象为：

```text
TOML 配置
  -> build-cf:
       打开输入 ROOT
       -> 读取 SE/ME THnSparseF
       -> 按 centrality、重分箱后的 mT 和可选 qn 分组
       -> 生成 phi_all 与重分箱后的逐 phi SE 投影
       -> 按配置生成积分或逐 phi/逐 qn ME 投影
       -> 归一化 SE/ME
       -> CF3D = SE_norm / ME_norm
       -> 写 slices/... 与 meta/SliceCatalog
  -> fit:
       读取 CF ROOT 与 SliceCatalog
       -> 选择 fit_selection 中的切片
       -> 解析 fit phi 坐标语义
       -> 可选准备 finite-source Coulomb kernel
       -> 对每个切片拟合 diag/full Levy 模型
       -> 写 per-slice fit artifacts
       -> 写 FitCatalog、CoulombKernelCatalog、TSV、R2_vs_phi、report ROOT
```

### 代码位置

- `app/main.cpp`：CLI 入口，分派 `build-cf` 与 `fit`。
- `include/exp_femto_3d/Types.h`：配置结构、catalog entry、fit result、Coulomb mode 等数据契约。
- `src/Config.cpp`：TOML 解析和配置校验。
- `src/Workflow.cpp`：CF 构建、SliceCatalog 读写、Levy/Coulomb 模型、fit、summary 和 report 输出。
- `tests/WorkflowSmokeTest.cpp`：toy sparse 到 CF、fit、summary/report 的 ROOT-backed smoke 覆盖。
- `tests/CoulombKernelValidationTest.cpp`：Coulomb mode、\(q_{\rm inv}\to k^*\)、表插值和 CATS 行为验证。

## 1. 输入 sparse 与切片定义

### 数学/物理公式

输入 same-event 和 mixed-event 统计可抽象为两个 7 维 histogram：

\[
H_{\rm SE}(q_{\rm out},q_{\rm side},q_{\rm long},m_T,c,q_n,\phi),
\]

\[
H_{\rm ME}(q_{\rm out},q_{\rm side},q_{\rm long},m_T,c,q_n,\phi).
\]

其中 \(c\) 是中心度，\(q_n\) 是第 5 轴的 event-shape selector。对配置中的一个中心度区间 \(C_a=[c_{\min},c_{\max}]\)、一个重分箱后的 \(m_T\) 区间 \(M_b=[m_{T,\min},m_{T,\max}]\)，以及 qn-integrated 区间或配置的 qn 区间 \(Q_l\)，build 阶段构造一个 group：

\[
g=(C_a,M_b,Q_l).
\]

每个 group 产生一个 phi-integrated 切片和所有逐 phi 切片：

\[
\Phi_{\rm all}=[\phi_{\min},\phi_{\max}],
\]

\[
\Phi_k=[\phi_{k,\min},\phi_{k,\max}],\qquad k=1,\ldots,N_\phi .
\]

### 抽象操作

配置中的 `[[bins.centrality]]`、rebin 后的 `[[bins.mt]]` 和可选
`[[bins.qn]]` 定义 build 分组。`[[fit_selection.centrality]]` 与
`[[fit_selection.mt]]` 定义 fit 阶段要消费哪些 build group；显式 range
模式在配置期精确匹配，native/factor 动态 mT group 则在读取
`SliceCatalog` 后校验，不能只写一个新的部分重叠区间。

输入对象路径按 TOML 拼接：

```text
<task_name>/<same_event_subtask>/<sparse_object_name>
<task_name>/<mixed_event_subtask>/<sparse_object_name>
```

### 代码位置

- `src/Config.cpp`：`LoadApplicationConfig()`、`ValidateApplicationConfig()`、`ParseRangeBinArray()`。
- `src/Workflow.cpp`：`BuildSparseObjectPath()`、`MatchSelectedBin()`。
- `src/Workflow.cpp`：`RunBuildCf()` 中 `GetAxis(4)`、`GetAxis(3)`、`GetAxis(6)` 分别选择 centrality、\(m_T\)、\(\phi\)。
- `tests/WorkflowSmokeTest.cpp`：toy `THnSparseF` 明确用 7 维轴填充输入。

### build.rebin 的输出分组

`build.rebin.mt` 和 `build.rebin.phi` 不会在最终 `TH3D` 上调用 ROOT 的
`Rebin`。当前实现是在 sparse 投影之前，先把输入轴上的连续 normal bins
聚合成输出 selection，再对每个 selection 执行原始三维投影。这样可以保留
`q_{\rm out}/q_{\rm side}/q_{\rm long}` 的分箱不变，只改变 \(m_T\) 和
\(\phi\) 的切片语义。

- `enabled = false`：轴按原始 normal bins 一格一切片。
- `enabled = true` 且给出 `factor`：把连续 normal bins 按整数因子合并；可选
  `min/max` 必须与输入轴边界对齐。
- `enabled = true` 且给出 `[[bins.mt]]` / `[[bins.phi]]`：按显式物理区间
  生成输出 selection，区间必须对齐输入轴边界。
- `phi_all` 始终覆盖输入 \(\phi\) 轴的完整 normal-bin 范围。
- 当 `build.map_pair_phi_to_symmetric_range = true` 时，每个非积分
  \(\phi\) selection 都不能跨越 \(\pi/2\) 映射接缝；这条规则同时适用于
  native、factor 和显式 ranges 模式。
- rebin 开启时，`SliceCatalog` 会用输出序号写入 `group_id` / `slice_id`，避免
  细分 bin 在文件路径里撞名。

- `src/Config.cpp`：`ParseAxisRebinConfig()`、`ValidateAxisRebinConfig()`。
- `src/Workflow.cpp`：`ResolveAxisSliceSelections()`、`ValidatePhiMappingSeam()`、
  `ValidateUniqueSliceIdentifiers()`。
- `tests/BuildCfRebinTest.cpp`：factor/ranges、边界失败，以及 qn/phi/mT

## 2. `build-cf`：SE/ME 投影、归一化与三维相关函数

### 数学/物理公式

对给定 group \(g=(C_a,M_b,Q_l)\) 和 SE phi 区间 \(\Phi\)，same-event 三维投影为

\[
S_g^\Phi(\mathbf q)
=
\sum_{m_T\in M_b}\sum_{c\in C_a}\sum_{q_n\in Q_l}\sum_{\phi\in\Phi}
H_{\rm SE}(\mathbf q,m_T,c,q_n,\phi).
\]

mixed-event 投影有两个模式。

默认 `build.split_mixed_event_by_phi = false` 时，逐 phi SE 切片共享同一个 group 内 phi-integrated ME 分母：

\[
M_g^{\rm all}(\mathbf q)
=
\sum_{m_T\in M_b}\sum_{c\in C_a}\sum_{q_n\in Q_{\rm ME}}\sum_{\phi\in\Phi_{\rm all}}
H_{\rm ME}(\mathbf q,m_T,c,q_n,\phi).
\]

可选 `build.split_mixed_event_by_phi = true` 时，逐 phi SE 切片使用相同 phi 区间的 ME 分母：

\[
M_g^\Phi(\mathbf q)
=
\sum_{m_T\in M_b}\sum_{c\in C_a}\sum_{q_n\in Q_{\rm ME}}\sum_{\phi\in\Phi}
H_{\rm ME}(\mathbf q,m_T,c,q_n,\phi).
\]

phi-integrated 切片在两种模式下都使用完整 phi 范围。这里
\(Q_{\rm ME}=Q_l\) 对应 `split_mixed_event_by_qn = true`；否则
\(Q_{\rm ME}=Q_{\rm all}\)，即 ME 保持 qn 积分。

`build.split_same_event_by_qn = true` 时，build 额外写出 qn-specific SAME
切片。默认 `build.split_mixed_event_by_qn = false` 时，这些切片仍使用全
qn 轴积分的 ME 分母；可选 `build.split_mixed_event_by_qn = true` 时，
ME 分母使用当前 qn-specific SAME 切片相同的 qn 区间。qn-all 切片在两种
qn 模式下都保持完整 qn 范围。

代码按三维 histogram 当前可见范围做带 bin width 的积分：

\[
I_{\rm SE}^\Phi
=
\int S_g^\Phi(\mathbf q)\,d^3q,
\qquad
I_{\rm ME}^\Phi
=
\int M_g^\Phi(\mathbf q)\,d^3q.
\]

归一化后：

\[
\widehat S_g^\Phi(\mathbf q)=\frac{S_g^\Phi(\mathbf q)}{I_{\rm SE}^\Phi},
\qquad
\widehat M_g^\Phi(\mathbf q)=\frac{M_g^\Phi(\mathbf q)}{I_{\rm ME}^\Phi}.
\]

输出相关函数为逐 bin 比值：

\[
C_g^\Phi(\mathbf q)
=
\frac{\widehat S_g^\Phi(\mathbf q)}
       {\widehat M_g^\Phi(\mathbf q)}.
\]

用于 1D QA 投影时，另两个动量轴限制在

\[
|q_j|<0.04\ {\rm GeV}/c,
\]

然后对窗口内 bin 求平均，而不是简单积分。

### 抽象操作

`build-cf` 不直接拟合物理模型。它只把 sparse 中的 SE/ME 统计变成带显式 metadata 的三维 CF 切片：

```text
SE sparse + ME sparse
  -> centrality/mT/phi projection
  -> normalize each 3D projection by visible integral
  -> divide normalized SE by normalized ME
  -> write raw SE, raw ME, CF3D, CF3D 1D projections
  -> append one SliceCatalog row
```

零积分处理：

- 如果默认积分 ME 分母为零，整个 centrality/\(m_T\) group 被跳过。
- 如果 `split_mixed_event_by_qn = true` 且某个 qn-specific group 的 ME
  分母为零，该 qn group 被跳过。
- 如果某个 SE phi 切片为零，该切片被跳过。
- 如果 `split_mixed_event_by_phi = true` 且某个逐 phi ME 分母为零，该切片被跳过。

- `src/Workflow.cpp`：`RunBuildCf()` 是 build 阶段入口。
- `src/Workflow.cpp`：`IntegralVisibleRange()` 负责可见范围积分。

## 3. phi 坐标映射与 `SliceCatalog`

### 数学/物理公式

输入 sparse 的原始 phi 坐标记为

\[
\phi_{\rm raw}\in[0,\pi].
\]

当 `build.map_pair_phi_to_symmetric_range = true` 时，代码只对中心值大于 \(\pi/2\) 的非积分切片做展示坐标映射：

\[
\phi_{\rm display}
=
\begin{cases}
\phi_{\rm raw}-\pi, & \phi_{\rm raw}>\pi/2,\\
\phi_{\rm raw}, & \phi_{\rm raw}\le \pi/2.
\end{cases}
\]

对应区间上下边界也同步减去 \(\pi\)。因此展示区间可落在

\[
[-\pi/2,\pi/2].
\]

phi-integrated 切片没有单一中心角，fit/result 中的 \(\phi\) 为 `NaN`。

### 抽象操作

`SliceCatalog` 是 build 和 fit 之间的语义契约。它同时保存：

- raw phi 区间和中心；
- display phi 区间和中心；
- qn 区间、标签和是否为 qn-integrated；
- build 阶段是否使用对称 phi 映射；
- build 阶段 ME 分母是否逐 phi 切分；
- build 阶段 ME 分母是否逐 qn 切分；
- build 阶段 \(m_T\) 和 \(\phi\) rebin 是否启用、使用哪种 mode；
- 每个切片的 ROOT object path。

fit 阶段的 phi 语义：

- 默认不写 `[fit].map_pair_phi_to_symmetric_range` 时，fit 跟随输入 CF 文件 `SliceCatalog` 记录的 build 语义。
- 显式写 `true` 或 `false` 时，fit 从 `raw_phi_*` 重新解释切片坐标，不需要重建 CF。
- 如果当前 TOML 的 build 映射值和输入 CF metadata 不一致，fit 会警告并信任输入 CF 文件。
- 当 \(m_T\) group 由 native/factor rebin 动态生成时，省略
  `[[fit_selection.mt]]` 表示消费 catalog 中全部 \(m_T\) group；显式
  `[[fit_selection.mt]]` 必须在 `meta/SliceCatalog` 中找到精确匹配。该校验在
  reset fit ROOT 输出文件之前完成。
- `split_same_event_by_qn = true` 时，qn-all 切片保留原 cent/\(m_T\)
  `group_id`；qn-specific 切片在 `group_id` 后追加 qn label，例如
  `__qn1`。fit 默认按 centrality/\(m_T\) 选择，因此会同时拟合 qn-all
  和所有已写入的 qn-specific 切片。
- `split_mixed_event_by_qn = false` 时，qn-specific 切片只切 SAME 侧；
  `true` 时 ME 分母跟随相同 qn 区间。旧 `SliceCatalog` 缺少该 metadata
  时按 `false` 读取。

## 4. 3D Levy/Bowler-Sinyukov fit 模型

### 数学/物理公式

当前 fit 模型的公共形式为

\[
C_{\rm model}(\mathbf q)
=
N
\left[
(1-\lambda_{\rm eff})
+
\lambda_{\rm eff} K_C(\mathbf q)
\left(1+\exp[-E(\mathbf q)]\right)
\right]
B(\mathbf q).
\]

其中 \(N\) 是 normalization，\(\lambda_{\rm eff}\) 由 `use_core_halo_lambda` 控制：

\[
\lambda_{\rm eff}
=
\begin{cases}
\lambda, & \texttt{use\_core\_halo\_lambda=true},\\
1, & \texttt{use\_core\_halo\_lambda=false}.
\end{cases}
\]

可选二次 baseline 为

\[
B(\mathbf q)
=
\begin{cases}
1+b_2(q_{\rm out}^2+q_{\rm side}^2+q_{\rm long}^2),
& \texttt{use\_q2\_baseline=true},\\
1, & \texttt{use\_q2\_baseline=false}.
\end{cases}
\]

`model = "diag"` 时只拟合对角半径：

\[
A_{\rm diag}(\mathbf q)
=
\frac{
R_{\rm out}^2q_{\rm out}^2
+R_{\rm side}^2q_{\rm side}^2
+R_{\rm long}^2q_{\rm long}^2
}{(\hbar c)^2},
\]

\[
E_{\rm diag}(\mathbf q)
=
\left[\max(A_{\rm diag},0)\right]^{\alpha/2}.
\]

`model = "full"` 时拟合完整对称 \(R^2\) 矩阵：

\[
A_{\rm full}(\mathbf q)
=
\frac{
R_{\rm out}^2q_{\rm out}^2
+R_{\rm side}^2q_{\rm side}^2
+R_{\rm long}^2q_{\rm long}^2
+2R_{\rm outside}^2q_{\rm out}q_{\rm side}
+2R_{\rm outlong}^2q_{\rm out}q_{\rm long}
+2R_{\rm sidelong}^2q_{\rm side}q_{\rm long}
}{(\hbar c)^2},
\]

\[
E_{\rm full}(\mathbf q)
=
\left[\max(A_{\rm full},0)\right]^{\alpha/2}.
\]

full 模型会要求 \(R^2\) 矩阵半正定；若对角项、二阶主子式或三维行列式低于容差，模型值返回惩罚值。

拟合范围是一个立方体：

\[
|q_{\rm out}|,|q_{\rm side}|,|q_{\rm long}|
\le
\texttt{fit.fit\_q\_max}.
\]

当前默认参数边界包括：

- \(0.5\le N\le 1.5\)
- \(0\le\lambda\le 1\)
- \(0.01\le R_{\rm out}^2,R_{\rm side}^2,R_{\rm long}^2\le 400\)
- full 模型的 \(R_{\rm outside}^2,R_{\rm outlong}^2,R_{\rm sidelong}^2\)
  默认初值为 \(0\)，默认不设显式一维上下限，但仍受 full \(R^2\)
  矩阵半正定约束
- \(0.5\le\alpha\le 2.0\)
- \(b_2\) 的默认上下限由 `fit.fit_q_max` 计算，保证默认 \(q^2\)
  baseline 因子在拟合立方体内保持受控

### 抽象操作

每个 `CF3D` 切片独立拟合。`fit` 命令的 `--model full|diag` 可以覆盖 TOML 中的 `[fit].model`。
可选 `[fit.parameters.<name>]` 子表只覆盖显式写出的 `initial`、`min`、`max`；
未写字段继续使用上述默认值。`lambda` 和 `alpha` 还支持 `fixed_value`，
两条目标函数路径都会把它们固定到指定值。

拟合有两条目标函数路径：

1. `use_pml = false`：直接用 ROOT `TH3::Fit` 拟合归一化后的 `CF3D`。
2. `use_pml = true`：使用 raw SE/ME counts 构造 Poisson maximum likelihood。

PML 路径对每个可用 bin 使用 same count \(S_i\)、mixed count \(M_i\) 和模型比值 \(r_i\)。代码里的

\[
r_i
=
C_{\rm model}(\mathbf q_i)
\frac{\int S_{\rm raw}(\mathbf q)\,d^3q}
     {\int M_{\rm raw}(\mathbf q)\,d^3q}.
\]

当 \(S_i>0\) 且 \(M_i>0\) 时，单 bin 贡献为

\[
-2\ln L_i
=
-2
\left[
S_i\ln\frac{r_i(S_i+M_i)}{S_i(r_i+1)}
+
M_i\ln\frac{S_i+M_i}{M_i(r_i+1)}
\right].
\]

零 count 的边界情况有单独公式保护；非法或非有限模型值给大惩罚。

### PML profile-likelihood 详细诊断

对扫描参数 \(\boldsymbol\theta\) 和其余 free nuisance 参数
\(\boldsymbol\eta\)，profile 的数值定义为

\[
Q_{\rm prof}(\boldsymbol\theta)
=
\min_{\boldsymbol\eta}
\left[-2\ln L_{\rm PML}(\boldsymbol\theta,\boldsymbol\eta)\right].
\]

因此每个网格点都会临时固定 1–2 个扫描参数，再对所有其余 free
参数重新运行 MIGRAD；`hesse_strategy="all_attempts"` 时随后运行 HESSE，
`"none"` 时误差保存为 NaN，并明确记录 `hesse_ran=false` 与
`parameter_errors_valid=false`。可选写出的 likelihood slice 则为

\[
Q_{\rm slice}(\boldsymbol\theta)
=
-2\ln L_{\rm PML}(\boldsymbol\theta,\boldsymbol\eta_{\rm nominal}),
\]

它固定 nominal nuisance，仅用于检查
\(Q_{\rm prof}\le Q_{\rm slice}\)，不能代替 profile。

对同一 slice 的 nominal minimum 和全部 scan 有效点，先选择最低的全局诊断
reference \(Q_{\rm ref}\)，再统一计算

\[
\Delta(-2\ln L_{\rm PML}) = Q-Q_{\rm ref}.
\]

如果 profile 找到比 nominal 更低的 minimum，它只更新诊断文件中的
reference，不回写 production fit、`FitCatalog` 或 TSV。有效 profile
minimum 要求最终 objective 有限且不是 penalty、模型域有效，并且 MIGRAD
成功。HESSE/协方差质量与撞边界只记录，不作为淘汰条件。full
\(R^2\) 非半正定点归类为 `model_domain_invalid`，不写成有效
likelihood。

一个 slice 内的扫描保持串行。每点先从 nominal 向量独立启动；默认 retry 再使用正向/
反向相邻已解点 warm-start，并保留全部 attempts。coarse minimum 在每个轴
上均位于内部时，才在相邻 coarse 坐标包围的规则区间做一次加密。

`process` 后端只在 `profile_only` 下启用，将完整的
((centrality,m_T,q_n)) group 分配给独立进程。每个 worker 的 ROOT、legacy
TMinuit、PML context 与冻结 kernel 相互隔离，group 内仍按确定性顺序串行。
每组完成后先原子写 chunk；只有所有 chunk 的 input/scan/model digest 和
slice/scan catalog 都匹配，coordinator 才合并临时 ROOT 并原子替换最终输出。
因此中断不会破坏上一次完整结果，匹配的 chunk 可由 `resume=true` 复用。

每个 slice 的 PML evaluator 预先按原三重循环顺序构造 `PMLBinCache`，缓存
有效 bin 的坐标二次项、raw SE/ME counts 与冻结 Coulomb factor。objective
仍逐项顺次累加，不使用并行 reduction；每个新 slice 首次求值会与旧的
逐 histogram-bin 路径比较，容差为
\(\max(10^{-10},10^{-12}|Q|)\)。

finite-source 模式下，所有 profile 点都使用 nominal 流程已经为当前
group 生成的最终 Coulomb kernel。即使扫描半径参数，也不重建 kernel；
`ProfileLikelihoodCatalog` 记录这个冻结契约和 seed/final
\(R_{\rm eff}\)、\(k^*\) 表范围等 metadata。

独立 `profile_likelihood.root` 以 TTree 为数值真源：

- `meta/ProfileLikelihoodCatalog`：slice/scan、轴、网格、nominal/reference、
  refinement、成功/失败统计与 finite-source kernel metadata。
- `meta/ProfileParameterCatalog`：canonical name、Minuit index、标签/单位、
  有效边界、nominal 值和 fixed/free 状态。
- `profiles/<slice_id>/<scan_id>/ProfilePoints`：坐标、索引、raw objective、
  delta、状态、winner seed、attempt 离散度、全参数/误差/边界信息。
- 同目录 `AttemptPoints`：每次 nominal/邻点启动的 Minuit 状态与结果。
- 1D 展示只保留 `Profile1D`、可选 `Slice1D`、`NominalPoint`、
  `Canvas_1D`，以及按真实参数名命名的 `Nuisance_<parameter>` 轨迹；
  不再写重复的 `Nuisance_p<N>` 别名或 coarse/refined、failure、minimum、
  boundary 等独立 QA 图。
- 2D 展示只保留 `DeltaNeg2LogL2D`、`PointStatus2D`、`NominalPoint` 和
  `Canvas_2D`。失败类别、refinement、minimum 和边界仍由 TTree/catalog
  数值字段表达，不重复生成图形对象；失败点不使用 0 伪装成有效 likelihood。

所有 contour 都明示标记为 `diagnostic only`，不做 68%/95% CL 解释。

## 5. Coulomb 修正模式

### 数学/物理公式

`fit.coulomb_mode = "none"` 时：

\[
K_C(\mathbf q)=1.
\]

`fit.coulomb_mode = "gamow"` 时，代码使用 like-sign \(\pi\pi\) 点源 Gamow factor。定义

\[
q_{\rm inv}\simeq |\mathbf q|
=
\sqrt{q_{\rm out}^2+q_{\rm side}^2+q_{\rm long}^2},
\]

\[
k^*_{\rm fm^{-1}}
=
\frac{q_{\rm inv}}{2\hbar c},
\qquad
a_B=387.5\ {\rm fm},
\]

\[
\eta=\frac{1}{k^*_{\rm fm^{-1}}a_B},
\]

\[
K_{\rm Gamow}
=
\frac{2\pi\eta}{\exp(2\pi\eta)-1}.
\]

代码把 Gamow 结果限制在 \([0,1]\)，并对 \(k^*\to0\) 和指数溢出做保护。

`fit.coulomb_mode = "finite_source"` 时，代码使用 CATS 生成 1D \(k^*\) 表。用于表查询的动量单位转换为

\[
k^*_{\rm MeV/c}
=
\frac{1}{2}q_{\rm inv}[{\rm GeV}/c]\times1000.
\]

表范围和分箱为：

\[
0\le k^*\le250\ {\rm MeV}/c,\qquad N_{\rm bin}=250.
\]

低于表首点时取首点值，高于表末点时返回 1，中间线性插值。

CATS 源使用球形 Gaussian radial source：

\[
S(r;R)
=
4\pi r^2(4\pi R^2)^{-3/2}
\exp\left[-\frac{r^2}{4R^2}\right].
\]

当前 finite-source 半径从 phi-integrated seed fit 的对角半径得到：

\[
R_{\rm eff}
=
\sqrt{
\frac{R_{\rm out}^2+R_{\rm side}^2+R_{\rm long}^2}{3}
}.
\]

finite-source CATS kernel 只包含 Coulomb，不包含 quantum statistics；代码设置 `SetQuantumStatistics(0)`，QS 仍由 Bowler-Sinyukov 模型中的 \(1+\exp[-E(\mathbf q)]\) 提供。

### 抽象操作

finite-source 模式按 centrality/\(m_T\) group 准备 kernel：

```text
for each selected cent/mT group:
  find phi_all slice
  fit phi_all with Gamow
  compute seed R_eff
  build CATS finite-source kernel(seed R_eff)
  if finite_source_mode == iterative_1d:
      refit phi_all once with seed kernel
      compute final R_eff
      rebuild CATS kernel(final R_eff)
  fit all selected slices in the group with the final kernel
```

`fixed_1d` 使用 Gamow seed 半径直接生成最终 kernel。`iterative_1d` 只做一次 finite-source seed 更新，不做多轮收敛。

如果构建时没有 `EXP_FEMTO_3D_HAS_CATS=1`，`finite_source` 会在 fit 开始前失败；`none` 和 `gamow` 仍然可用。

- `src/Workflow.cpp`：`HasCatsFiniteSourceSupport()`。

- `src/Workflow.cpp`：`ComputeKStarMeV()`。

## 7. \(R^2(\phi)\) summary 与 \(\epsilon_f(m_T)\)

### 数学/物理公式

summary 阶段只使用非 phi-integrated 切片。每个 centrality/\(m_T\) group 内，代码把逐 phi fit 结果排序后生成 `TGraphErrors`。

对角半径趋势使用二阶余弦形式：

\[
R_i^2(\phi)
=
R_{i,0}^2+2R_{i,2}^2\cos(2\phi),
\qquad
i\in\{{\rm out,side,long}\}.
\]

full 模型中的交叉项使用：

\[
R_{\rm outside}^2(\phi)
=
R_{{\rm outside},0}^2+2R_{{\rm outside},2}^2\sin(2\phi),
\]

\[
R_{\rm outlong}^2(\phi)
=
R_{{\rm outlong},0}^2+2R_{{\rm outlong},2}^2\cos(2\phi),
\]

\[
R_{\rm sidelong}^2(\phi)
=
R_{{\rm sidelong},0}^2+2R_{{\rm sidelong},2}^2\sin(2\phi).
\]

\(\alpha\)、\(\lambda\)、\(b_2\) summary 使用常数拟合。

report 中的 \(\epsilon_f(m_T)\) 来自 \(R_{\rm side}^2(\phi)\) 的二阶谐波：

\[
R_{\rm side}^2(\phi)
=
R_{s,0}^2+2R_{s,2}^2\cos(2\phi),
\]

\[
\epsilon_f
=
\frac{2R_{s,2}^2}{R_{s,0}^2}.
\]

实现中 `FitSideRadiusSecondHarmonic()` 直接拟合

\[
y=a+b\cos(2\phi),
\]

然后写出

\[
\epsilon_f=b/a,
\]

这与上式中的 \(b=2R_{s,2}^2\)、\(a=R_{s,0}^2\) 等价。

phi fit 区间跟随当前 fit phi 语义：

\[
\phi\in[0,\pi]
\quad\text{或}\quad
\phi\in[-\pi/2,\pi/2].
\]

### 抽象操作

summary 输出分两类：

1. detailed fit ROOT 与 report ROOT 都写 `summary/R2_vs_phi/<group_id>/...`。
2. report ROOT 额外写更面向人工浏览的：

```text
source_parameters/<cent>/<mt>/source_parameters_overview_canvas
source_parameters/<cent>/<mt>/<qn_label>/source_parameters_overview_canvas
eps_vs_mt/<cent>/epsf_vs_mt
eps_vs_mt/<cent>/epsf_vs_mt_canvas
eps_vs_mt/<cent>/<qn_label>/epsf_vs_mt
eps_vs_mt/<cent>/<qn_label>/epsf_vs_mt_canvas
```

其中不带 `<qn_label>` 的路径对应 qn-all，并保持旧输出路径；带
`<qn_label>` 的路径只在 qn-specific 切片存在时写入。
